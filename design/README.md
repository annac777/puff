# Design handoff

Design should cover `quiet`, `considering`, `gentle_nudge`, `checkpoint`, `on_break` and `resume` using the frozen contract in `docs/mvp-scope.md`.

Deliver:

- One frame per mode at 320 px content width.
- Default, hover, pressed, focus and disabled button states.
- Gentle-nudge, checkpoint, break and resume pet states.
- Empty/unavailable-tab and restricted-page states.
- Motion trigger, duration, easing and reduced-motion behavior.
- First-run privacy copy.
- SVG or PNG assets exported to `extension/assets/` with lowercase kebab-case names.

The current CSS pet is deliberately a placeholder so UX work can proceed independently.
